# Match Points Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every finished match awards points (result + survival + crate, halved vs bots, zero for leavers), stored per device and per account, shown in the lobby, on the game-over card and on the leaderboard.

**Architecture:** Spec: `docs/superpowers/specs/2026-09-05-points-design.md`. A pure formula (`server/src/points.ts`), a store (`server/src/db/pointsStore.ts`, migration 0010), the award computed in `index.ts` `onMatchEnd` and returned to `Room`, which puts each player's award into their own `game:end`; a `points:total` message on socket open. Client keeps the number in `lib/points.ts` and three views render it.

**Tech Stack:** Bun, TypeScript, Drizzle/SQLite, Vue 3.

## Global Constraints

- Table: win 10 / draw 3 / loss 1; +2 per round after the first; crate +2; vs bot `Math.ceil(sum / 2)`; own disconnect 0; practice never reaches `onMatchEnd`.
- Protocol additions are optional fields / new message types only.
- Migration `packages/server/drizzle/0010_add_points.sql`, journal idx 10, tag `0010_add_points`.
- Storage key on the client: `wheee:points-v1`.

```ts
/**
 * What a finished match is worth to one player. Points only ever go up: the
 * number is a reason to come back, not a rating. See the design spec for why
 * a draw beats a loss and a leaver gets nothing.
 */
export type PointsInput = {
  result: 'win' | 'draw' | 'loss'
  /** Round the match ended in, 1-based. */
  rounds: number
  vsBot: boolean
  /** Lost by dropping/leaving — the server cannot tell those apart. */
  ownDisconnect: boolean
  /** Picked up the crate this match. */
  crate: boolean
}

const RESULT_POINTS: Record<PointsInput['result'], number> = { win: 10, draw: 3, loss: 1 }
const ROUND_POINTS = 2
const CRATE_POINTS = 2

export function pointsFor(i: PointsInput): number {
  if (i.ownDisconnect) return 0
  let sum = RESULT_POINTS[i.result] + ROUND_POINTS * Math.max(0, i.rounds - 1) + (i.crate ? CRATE_POINTS : 0)
  if (i.vsBot) sum = Math.ceil(sum / 2)
  return sum
}
```

- [ ] Implement `pointsStore.ts`:

```ts
import { eq, sql } from 'drizzle-orm'
import { db, schema } from './index.js'
import { ensureStatsRow } from './matchStore.js'

/**
 * The player's points, kept twice: on the device (every player has one) and on
 * the account (only signed-in players). The account total is the one shown
 * when there is an account, so a guest who signs in starts a fresh count —
 * claiming device points onto an account is a later feature.
 */
export function awardPoints(deviceId: string | null, userId: string | null, earned: number): number {
  return db.transaction((tx) => {
    const now = new Date()
    let deviceTotal = 0
    if (deviceId) {
      tx.insert(schema.devicePoints)
        .values({ deviceId, points: earned, matches: 1, updatedAt: now })
        .onConflictDoUpdate({
          target: schema.devicePoints.deviceId,
          set: { points: sql`${schema.devicePoints.points} + ${earned}`, matches: sql`${schema.devicePoints.matches} + 1`, updatedAt: now },
        })
        .run()
      deviceTotal = tx.select({ p: schema.devicePoints.points }).from(schema.devicePoints).where(eq(schema.devicePoints.deviceId, deviceId)).get()?.p ?? 0
    }
    if (!userId) return deviceTotal
    ensureStatsRow(tx, userId)
    tx.update(schema.userStats)
      .set({ points: sql`${schema.userStats.points} + ${earned}`, updatedAt: now })
      .where(eq(schema.userStats.userId, userId))
      .run()
    return tx.select({ p: schema.userStats.points }).from(schema.userStats).where(eq(schema.userStats.userId, userId)).get()?.p ?? 0
  })
}

export function getPoints(deviceId: string | null, userId: string | null): number {
  if (userId) {
    const row = db.select({ p: schema.userStats.points }).from(schema.userStats).where(eq(schema.userStats.userId, userId)).get()
    if (row) return row.p
  }
  if (!deviceId) return 0
  return db.select({ p: schema.devicePoints.points }).from(schema.devicePoints).where(eq(schema.devicePoints.deviceId, deviceId)).get()?.p ?? 0
}
```

`matchStore.ts`: rename the private `ensureStats` to an exported `ensureStatsRow` (keep the local calls), add `points: 0` to its insert, select `points: schema.userStats.points` in `getPlayerLeaderboard`, and order by `desc(points), desc(wins), desc(gamesPlayed), asc(userId)`. `PlayerLeaderboardEntry` gains `points: number`.
